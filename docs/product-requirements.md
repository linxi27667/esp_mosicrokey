# 首版产品需求

基线：2026-10-01，当前版本 v0.1.9；执行用户确认的双 AI 与 TF 游戏计划。

## 范围与验收

| 编号 | 行为 | 软件实现 / 验收证据 |
|---|---|---|
| VOICE-01 | 小智配网、激活、录音、真实对话、播放与中断 | 真实应用/协议/ES8311 已编入；实板与服务验收待完成 |
| AI-CO-01 | 两项 AI 服务驻留，前台独占音频与游戏输入 | 业务状态机、音频入口与迟到回调均检查焦点；主机状态机验证通过 |
| AI-CO-02 | ESPClaw 请求跨页面后台执行，可取消 | 真实 claw_core 已集成，HTTPS 取消和真实兼容 API 已实测；完整语音并发仍待小智激活 |
| AGENT-01 | 串口输入文字需求，配置兼容 API 地址、模型与密钥 | UART 命令与专用 NVS 已实现；不回显、不输出密钥 |
| GAME-01 | AI 创作/修改、校验、安装并枚举 TF 游戏版本 | 五工具、修复反馈、源码分页读取、不可变版本已实现 |
| GAME-02 | 重启重新发现，启动、方向控制、得分、失败、重开与退出 | 贪吃蛇与运行时主机验证通过；TF 重启实板验证待完成 |
| GAME-03 | 脚本超时、内存耗尽、异常安全返回游戏库 | 主机限制/故障返回、真实设备 VM 限制自检通过 |
| UI-01 | 160×128 横屏，中文、焦点、空库、错误、长文本 | 共享 LVGL 9.5 页面 13 个状态实际渲染并检查 |
| HW-01 | SPI 屏、四线 TF、六按键、板载音频 | BSP 已编译，电气与实物验证待完成 |
| STABLE-01 | 连续两小时、切换 100 次，无崩溃/WDT/持续内存增长 | 10-02 USB独立7201.29秒、100次游戏加载退出、600导航命令通过，最低/平均30.3FPS，无记录崩溃/复位/WDT；堆趋势与项目栈余量已复核，后台24请求21成功3断网错误并自动恢复。完整语音与实体外设场景仍待测 |
| PERF-01 | 游戏 30 FPS，后台创作时持续不低于 20 FPS | 固件按 33 ms 调度并输出 FPS；设备性能待测 |

游戏逻辑画布 160×128，首版无声音。小智只有获得前台焦点时开启语音；离开时停止采集、取消对话、清理播放。后台安装新游戏版本不替换正在运行的 VM。

缺卡时小智仍可工作；ESPClaw 使用有限 RAM 会话，游戏工具返回存储错误。不得自动格式化 TF。配置更改及重挂在对应操作忙碌时返回忙碌。

用户仅接 USB 时增加临时预览用例：Agent 通过真实 game_preview 发布同一受限 VM 的 Lua 游戏，设备游玩和串口输入回放；源码与画布可导出用于验证。界面和工具结果标记临时、重启丢失，TF 五工具仍返回真实存储状态。该用例不替代 GAME-01/02 的 TF 验收。

模型运行于外部服务；设备执行请求、上下文和工具循环。需要可用 Wi-Fi、小智服务以及支持 tools 的 OpenAI 兼容 Chat Completions 服务。首版只支持已注册的游戏工具，不向模型暴露任意文件、网络、GPIO 或通用代码执行权限。
