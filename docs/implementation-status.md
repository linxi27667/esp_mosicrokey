## 实板驱动的修复

- 缺 TF 时上游用户消息只有 text、没有 message_json，导致兼容 API 收到仅 system 消息；临时历史补齐 role/content，并保持 8 条/16 KiB 上限。
- 小智音效和 codec 在离页后仍可能工作；前台门控覆盖采集、输出、唤醒、迟到 TTS 和解码。
- 长 HTTPS 模型等待阻塞取消；改为可取消轮询，异步请求避开不兼容的连接池；401 保留真实鉴权原因。
- 免费模型可能空回复或把工具调用打印成文本；指令和 tool_choice 明确实际调用要求，发布结论仍只依赖真实工具结果。
- 429/503 可能打断多轮创作；增加两次有界退避，共享每轮原超时并支持取消，已发布游戏的结果保留到最终错误提示。
- v0.1.3 丢弃超过总期限才到达的 HTTP 200；测试统计按本轮实际请求 ID 去重。补丁重新以固定上游提交生成，并通过离线反向应用和原始字节哈希核验。
- v0.1.9 仅对异步 POST 正文未完成状态的 WRITE_DATA 继续相同连接和已保存偏移；关闭/请求头/负值写失败不重试。48 项实际 HTTP 传输检查覆盖原始分段发送、取消、恢复、重连及原期限。
- v0.1.8 将 TLS 连接后的单次 I/O 等待限制为 100 ms，保留原连接预算与整请求期限；连接期取消仍应用短 I/O，断开/重连恢复连接预算。36 项实际 HTTP 传输故障注入覆盖这些边界。DNS/TCP 建立仍由 SDK 执行，不承诺所有网络阶段都在 100 ms 取消。
- v0.1.7 诊断页面移除写死的旧版号，提示 status 查询真实固件版本；13 状态重新渲染。
- v0.1.6 参考示例使用板载 AI 修复并导出的 V3：每次移动只接受一次转向，有界找食物、满屏胜利；32 项实际源码回放通过，固件 demo/Agent 参考/VM 自检共用该源码。
- v0.1.5 新增 gameask 创作意图及真实发布判定：模型仅文字声称成功会返回未发布。本次创作初始上下文只含当前 USER，普通聊天历史保持；448 项业务检查涵盖意图、发布和当前 USER。
- v0.1.4 新增复位原因与运行时间诊断。长测线程临时防止电脑自动睡眠，检测主机日志间隙和设备重启；故障注入验证清理与证据保存，旧版 77 分钟中断记录保留为部分结果。
- v0.1.1 后台网络活动触发绘图墙钟预算；v0.1.2 隔离游戏和主要网络/UI 任务，保留 10 ms 帧预算及指令上限继续实测。
- AI 生成游戏通过语法和短探测后仍有食物/得分逻辑缺陷；增加只读源码导出及 Snake 实际 VM 玩法回放，反馈模型修复。通用安装校验不承诺玩法正确。

## 验证边界

USB 临时游戏显示“临时”，工具返回 persistent=false，重启后丢失；不代表 TF 安装成功。真实 VM 画布导出不代表实体屏颜色正确。小智激活必须绑定用户账号，智谱文本 API Key 不能替代该绑定。

构建不依赖原工作目录。按用户要求未继续备份，本轮正常分区烧录保留 NVS，没有整片擦除。源码、日志和发布镜像不包含 Wi-Fi 密码或模型密钥。
