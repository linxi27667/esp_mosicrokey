# ADR-0001 首版双 AI 与 TF Lua 游戏

状态：已接受（依据用户明确确认的实施计划）。日期：2026-10-01。

## 背景

首版需要同时驻留真实小智与 ESPClaw，让后者创建、安装、修改 TF 游戏，并在小屏设备即时游玩。共享音频、输入、显示和存储，且小智原固件更新不能覆盖集成工程。

## 决策

采用独立 ESP-IDF 6.1.0 S31 工程；以业务状态机、无平台私有类型的服务接口与上游适配器划分。唯一入口、唯一板工厂、唯一 Wi-Fi 初始化和唯一 LVGL 上下文。保留 compoment 拼写。

两项 AI 后台共存，前台资源独占。游戏使用受限 Lua 5.5、固定 160×128 API；TF 暂存、校验、不可变修订及 READY 提交标记。ESPClaw 仅暴露五项游戏工具，小智保留激活但禁用完整固件升级。

完整键盘、HID、蓝牙音箱、无线控制器及通用存档后移。

## 理由与影响

独立版本库允许后台创作时继续玩旧版本；固定 API 可在主机和设备回放输入。接口隔离避免业务依赖上游私有类型；原音频链保留但增加产品焦点门控。采用自建 Lua 动态运行时，Mosaico 只作开发流程参考，不引入其 C 游戏/BSP 构建依赖。

SDK S31 为预览目标，屏幕参数、实际时限、语音与真实 API、并发帧率和稳定性须实板验收。版本保留和断电暂存会增加 TF 占用，后续再设计清理策略。更改运行时 API 或包格式时需要显式兼容性决策。
